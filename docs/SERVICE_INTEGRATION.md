# Service integration

Aura Core owns identity, organization membership, permissions, service activation and billing. AuraHub reuses the existing dashboard shell. The first adapter connects to the AuraMenu-managed editor and publication APIs. Billing state and the subscription plan limit service actions server-side. Start with explicit owner-verified links for legacy records, retain existing access through staging, and compare new decisions with current access before any cutover.

AuraMenu retains control of menu IDs, templates, public URLs, QR/NFC destinations and publishing. AuraHub can show scoped status and provide a route to the management surface. The standalone sign-in and published-menu handles remain valid during rollout. Follow the [AuraMenu integration handoff](agent-handoff/AURAMENU_INTEGRATION.md).
