# Roadmap

1. Reviewed text/voice extraction, CSV import and explicit conversational edits integrated with the existing editor/preview.
2. Eliminate silent example facts and stale reviewed changes; verify persistence and mobile behavior.
3. Private organization drafts using existing customer identity, with tenant isolation and version checks.
4. Repair account integration and configure same-origin API routing/central identity redirect flow. Verify registration, recovery, return paths and account ownership end to end.
5. Attach reviewed drafts to existing requests with authenticated owner evidence; preserve legacy contracts.
6. Verify administrative activation and public URL/QR journey against an isolated staging database.
7. Add verified provider checkout/webhook contracts when an eligible account is available.
8. Unified dashboard/service ownership and deterministic sales quotes from the configured catalogue.
9. Model-assisted structured extraction behind enforced per-tenant budgets; AuraWeb templates and AuraAds intake after AuraMenu acceptance.

A completed local component is not a deployed product or a passed full customer acceptance test.
